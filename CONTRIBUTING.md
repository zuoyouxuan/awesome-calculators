# Contributing

Thank you for considering contributing to this awesome list!

## Guidelines

1. **Research first** — Make sure the tool/resource isn't already listed.
2. **Keep it alphabetical** — Entries must be in alphabetical order within their category.
3. **One line per entry** — Format: `- [Name](URL) — Short description.`
4. **No affiliate links** — All submissions must be genuine recommendations.
5. **Free or freemium only** — Tools must have a meaningful free tier.
6. **One PR per entry** — Keep it focused and easy to review.

## Pull Request Process

1. Fork the repository.
2. Create a new branch: `git checkout -b add-awesome-tool`
3. Make your changes.
4. Commit with a clear message: `Add [Tool Name] to [Category]`
5. Push and open a PR.

Thanks for helping make this list better! 🚀
