## 総合計算プラットフォーム

_複数ドメインをカバーするオールインワン計算機プラットフォーム。_

- [**Calnex**](https://calnex.pro) — 147 以上の無料計算機、金融、健康、数学、物理、変換、日常生活を網羅。すべての計算は**ブラウザ内でローカル実行** — データのアップロードは一切なし、登録不要。12 言語対応。⭐

## 金融と投資

- [住宅ローン計算機](https://www.calculator.net/mortgage-calculator.html) — 定番の月々の支払い見積もり。
- [複利計算機](https://www.investor.gov/financial-tools-calculators/calculators/compound-interest-calculator) — 米国 SEC 公式複利ツール。
- [複利計算機（インタラクティブ）](https://calnex.pro/en_US/calculators/finance/compound_interest_calculator) — グラフ付き複利計算、日次/月次/年次の積立に対応。
- [ローン計算機](https://www.bankrate.com/loans/loan-calculator/) — Bankrate のローン償却計算。
- [WACC 計算機](https://calnex.pro/en_US/calculators/finance/wacc_calculator) — 企業の加重平均資本コスト。
- [ROI 計算機](https://www.omnicalculator.com/finance/roi) — 投資収益率の見積もり。
- [コーヒー複利ショッカー](https://calnex.pro/en_US/calculators/finance/coffee_compound) — 毎日のコーヒー代がもたらす驚きの機会費用。
- [割引と値上計算機](https://www.omnicalculator.com/finance/markup) — 割引と値上率の計算。

## 健康とフィットネス

- [体脂肪率計算機](https://www.omnicalculator.com/health/body-fat) — 体脂肪率の見積もり。
- [カロリー計算機](https://calnex.pro/en_US/calculators/health/calorie_calculator) — 活動レベルと目標に基づく1日のカロリー必要量。
- [出産予定日計算機](https://www.whattoexpect.com/due-date-calculator/) — 妊娠出産予定日の見積もり。
- [マクロ栄養素計算機](https://calnex.pro/en_US/calculators/health/macro_calculator) — フィットネス目標に合わせたタンパク質・炭水化物・脂質の目標値。
- [心拍数ゾーン計算機](https://calnex.pro/en_US/calculators/health/heart_rate_zone_calculator) — 最大心拍数に基づくトレーニングゾーン。
